# วงล้อศิลป์ถิ่นเรา — CEO Domain Quest

โครงเว็บวงล้อด้วย Next.js App Router, TypeScript และ CSS เขียนเอง ใช้ภาพต้นฉบับจาก `UI/Welcome/` ที่ผู้ใช้จัดเตรียมไว้ ฟอนต์ภาษาไทยอยู่ในโปรเจกต์ ไม่ต้องเรียก Google Fonts ขณะเปิดหน้าเว็บ

## เริ่มต้น

ใช้ Node.js 20.9 ขึ้นไป (รัน unit tests ด้วย Node.js 22.18 ขึ้นไป)

```sh
npm install
npm run dev
```

เปิด http://localhost:3000 ส่วนอุปกรณ์อื่นใน Wi-Fi เดียวกันให้เปิด `http://<IP ของคอมพิวเตอร์>:3000` และอนุญาตการเชื่อมต่อผ่านไฟร์วอลล์ของเครื่องหากจำเป็น

หากรันใน sandbox บน macOS แล้ว Turbopack แจ้ง `unable to start FSEvent stream` ให้ใช้ `WATCHPACK_POLLING=true npm run dev -- --webpack` แทน หากพอร์ต 3000 ถูกใช้แล้ว Next.js จะแสดงพอร์ตที่ว่างใน terminal

```sh
npm run typecheck
npm test
npm run build
npm start
```

## วิธีเล่น

1. นักเรียนหมุนวงล้อสี ระบบแสดงชื่อสีขนาดใหญ่ แต่ยังไม่แสดงโทนสี
2. ครูถามเด็กด้วยปากว่าเป็นโทนร้อนหรือโทนเย็น แล้วกด **ครู: เฉลยคำตอบ**
   สีเหลืองและสีม่วงเฉลยว่า **เป็นได้ทั้งสีโทนร้อนและสีโทนเย็น**
3. กด **ไปสุ่มภาพต่อ** ระบบโฟกัสวงล้อภาพและเบลอวงล้อสี
4. หมุนภาพ 1 ครั้ง ดูคู่สีและภาพ แล้วกดไปยังรอบถัดไป
5. ครบ **10 รอบ = สี 10 ครั้ง + ภาพ 10 ครั้ง** จะหยุดการสุ่ม โดยคงวงล้อไว้และแสดงปุ่มเริ่มใหม่

- หน้าหลักแสดงวงล้อและปุ่มควบคุมขนาดเล็ก ไม่มีแถบสรุป แถบนับสี หรือรายการผลการเล่น
- สื่อถูกกำหนดไว้ตายตัว: 8 สี และ 10 ภาพ ไม่มีแผงเพิ่ม/ลบตัวเลือก
- สีที่ออกครบ 2 ครั้งจะถูกนำออกหลังครูกดไปสุ่มภาพต่อ เพื่อรักษาความตรงกันระหว่างเข็มกับผลขณะเฉลย สีที่เหลือมีโอกาสเท่ากัน
- ภาพที่สุ่มได้จะถูกตัดออกทันทีเมื่อวงล้อหยุด รอบละ 1 ภาพ โดยยังแสดงภาพบนการ์ดผลลัพธ์ ครบ 10 รอบจะได้ภาพทั้ง 10 ภาพไม่ซ้ำกัน
- วงล้อที่เลือกอยู่กลางจอขนาดใหญ่ อีกวงย่อและเบลอไว้ด้านข้าง (มุมล่างบนจอแนวตั้ง) แตะวงล้อที่เบลอเพื่อเลือก แต่หมุนได้เฉพาะขั้นที่ถึงแล้ว ไม่สามารถข้ามขั้นเฉลย
- ปุ่มกลาง/ปุ่มด้านล่าง/Space ใช้หมุน เลข 1 และ 2 ใช้เลือกวงล้อ
- ป้องกันการกดซ้ำและการเปลี่ยนวงล้อระหว่างหมุน
- บันทึกขั้นตอน รอบที่จบแล้ว และการเปิด/ปิดเสียงไว้บนเบราว์เซอร์นี้ หากรีเฟรชขณะหมุน จะกลับไปก่อนเริ่มการหมุนครั้งนั้น
- เริ่มใหม่จะคืนสีทั้ง 8 สีและภาพทั้ง 10 ภาพ พร้อมเริ่มนับ 10 รอบใหม่
- โหมด TV ขยายพื้นที่วงล้อและรองรับ Fullscreen API พร้อม responsive และ reduced motion

## โหมดนาฬิกาถอยหลัง

เลือก **จับเวลา** จากเมนูโหมด หรือเปิด `/timer` ได้โดยตรง เป็นกิจกรรมแยกจากวงล้อ ใช้พื้นที่บันทึกของตัวเอง และกลับไปเล่นวงล้อต่อได้จากเมนู **วงล้อ**

- แสดงเวลาขนาดใหญ่กลางกรอบ `UI/Leafy wooden countdown display frame.png` พร้อมปุ่มเริ่ม พัก หรือนับต่อใต้กรอบ
- กดปุ่มฟันเฟืองเพื่อเปิดหน้าต่างตั้งค่า เริ่มต้น 10 นาที เลือกเวลา 5, 10, 15, 20 หรือ 30 นาที หรือตั้งเองตั้งแต่ 00:01 ถึง 99:59 รวมถึงรีเซ็ตและเปิดเต็มจอ TV
- การแก้เวลาในหน้าต่างยังไม่กระทบเวลาที่กำลังนับ กดบันทึกเพื่อหยุดและตั้งเวลาใหม่ แล้วกดเริ่มบนหน้าหลัก; กดยกเลิก ปิด หรือ Escape เพื่อใช้เวลาเดิมต่อ
- นับจากเวลาสิ้นสุดจริง จึงยังนับต่อเมื่อสลับโหมด ซ่อนแท็บ หรือรีเฟรชหน้า เวลาไม่ติดลบและแสดง “หมดเวลาแล้ว” เมื่อครบเวลา
- ตัวเลขใช้ฟอนต์อ่านง่ายและความกว้างคงที่ พร้อมคำสั่ง **ให้นักเรียนระบายสีภาพที่สุ่มได้ โดยใช้โทนสีที่สุ่มได้**
- ครูครีมขยับต่อเนื่องอย่างนุ่มนวล และเปลี่ยนท่าตามสถานะเวลา เคารพการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์
- เพลงประกอบเดิมเล่นวนเมื่อกดเริ่มจับเวลา พักเพลงพร้อมเวลา และเล่นต่อจากจุดเดิมเมื่อกดนับต่อ; รีเซ็ต ตั้งเวลาใหม่ หมดเวลา หรือออกจากโหมดจะหยุดเพลง
- เปิด–ปิดเพลงได้ในหน้าต่างฟันเฟือง โดยจำการตั้งค่าแยกจากวงล้อ ลดเสียงขณะเปิดหน้าต่างตั้งค่าและพักเสียงเมื่อซ่อนแท็บ หากกลับเข้าหน้าหรือรีเฟรชขณะกำลังนับ ให้คลิกหรือกด Enter/Space เพื่อให้เบราว์เซอร์อนุญาตเสียงอีกครั้ง

## รูปภาพสำหรับสื่อ

ใช้ตัวละคร **ครูครีม** ชุดใหม่จาก `UI/creamNew/` แทนภาพเดิมทุกจุด ทั้งข้างวงล้อ หน้าผลลัพธ์ และโหมดจับเวลา เลือก 6 ท่าตามขั้นตอน: ทักทาย → ลุ้นตอนหมุน → คิดตอนถาม → ให้กำลังใจตอนเฉลย → ชวนสุ่มภาพ → ฉลองเมื่อได้ภาพ/จบกิจกรรม ภาพต้นฉบับถูกใช้ผ่าน Next.js Image โดยไม่แก้ไขไฟล์

ใช้ภาพระบายสีจริงทั้ง 10 ภาพจาก `UI/img/`: 🥚 ไข่เค็มไชยา, 🦪 หอยนางรม, 🚤 เรือพระ, 🎭 หนังตะลุง, 🍈 เงาะโรงเรียน, 👗 ผ้าปาเต๊ะ, 🌳 ต้นยางพารา, 🛕 พระบรมธาตุไชยา, 🏝️ เกาะสมุย–เกาะพะงัน–หมู่เกาะอ่างทอง และ 🌺 ดอกบัวผุด โดยคัดลอกต้นฉบับไปที่ `public/wheel-images/` และผูกชื่อกับภาพใน `src/lib/activity.ts` ชื่อยาวแบ่งเป็นหลายบรรทัดบนวงล้อและปรับขนาดในผลลัพธ์ โดยคง ID ภาพเดิมสำหรับกิจกรรมที่บันทึกไว้ วงล้อใช้ภาพย่อผ่าน Next.js Image ส่วนการ์ดผลลัพธ์แสดงภาพเต็มในสัดส่วนแนวนอน พร้อมจัดพื้นที่ภาพให้พอดีกับจอโดยไม่เลื่อน

## เสียงประกอบ

ใช้เสียงที่ผู้ใช้จัดเตรียมไว้ใน `เสียงประกอบ/เสียงประกอบ.WAV` และ `เสียงตอบถูก/เสียงตอบถูก.WAV` แปลงเป็น MP3 ใน `public/audio/` เพื่อให้โหลดเร็วขึ้น โดยเก็บไฟล์ต้นฉบับไว้เหมือนเดิม

- เพลงเริ่มหลังผู้ใช้คลิกหรือกด Enter/Space ครั้งแรก แล้วเล่นวนระหว่างกิจกรรม
- ลดเสียงเพลงขณะถาม เฉลย ดูผลภาพ หรือเปิดกล่องเริ่มใหม่ เพื่อให้คุยกับนักเรียนได้ชัดเจน
- เมื่อครูกด **ครู: เฉลยคำตอบ** จะเล่นไฟล์เสียงตอบถูก 1 ครั้ง ไม่เล่นซ้ำเมื่อรีเฟรชหน้าผลลัพธ์
- ปุ่มเปิด/ปิดเสียงควบคุมทั้งเพลง เสียงตอบถูก และเสียงหมุน มีปุ่มนี้ในการ์ดผลลัพธ์ด้วย
- พักเสียงเมื่อซ่อนแท็บ หยุดเพลงเมื่อครบ 10 รอบ และเริ่มเพลงใหม่เมื่อเริ่มกิจกรรมใหม่

## โครงสร้าง

```text
UI/                        ภาพต้นฉบับจากผู้ใช้
public/wheel-images/       ที่เก็บภาพสำหรับวงล้อภาพ
public/audio/             เพลงประกอบและเสียงตอบถูกสำหรับเว็บ
src/app/                   หน้าเว็บ, metadata และ CSS
src/components/wheel-game.tsx   วงล้อกลางจอ หน้าคำถาม เฉลย และโหมด TV
src/components/countdown-mode.tsx  นาฬิกาถอยหลังและคำสั่งระบายสี
src/components/mode-navigation.tsx  สลับโหมดวงล้อและจับเวลา
src/components/lucky-wheel.tsx  วงล้อ SVG และการแสดงผลการหมุน
src/components/picture-placeholder.tsx  ภาพสำรองสำหรับรายการที่ไม่ได้กำหนดไฟล์
src/components/cream-mascot.tsx  ครูครีม 6 ท่าตามขั้นตอนการเล่น
src/components/icon.tsx         ไอคอน SVG
src/lib/wheel.ts                ข้อมูลเริ่มต้น การสุ่ม และคำนวณมุม
src/lib/activity.ts             ลำดับเกม กฎตัดสี 10 รอบ และการกู้คืนกิจกรรม
src/lib/activity-audio.ts       ควบคุมเพลง เสียงตอบถูก และระดับเสียงตามขั้นตอน
src/lib/countdown.ts            คำนวณเวลา พัก นับต่อ และกู้คืนตัวจับเวลา
src/lib/*.test.ts               ทดสอบกติกา การกดซ้ำ การกู้คืน และความตรงกันของเข็มกับผล
```

เปลี่ยนสีและรายการตั้งต้นได้ที่ `src/lib/wheel.ts` ปรับธีมและ responsive ได้ที่ `src/app/globals.css` ภาพเดิมถูกนำเข้าผ่าน Next.js Image โดยไม่แก้ไขไฟล์ต้นฉบับ

นี่เป็นโครงเริ่มต้นสำหรับคุยคอนเซ็ปต์ต่อ ยังไม่มีระบบบัญชีหรือการซิงก์ข้อมูลระหว่างอุปกรณ์ ต้องเปิดด้วยเบราว์เซอร์สมัยใหม่; Smart TV รุ่นเก่าที่มีเบราว์เซอร์ล้าสมัยอาจต้องใช้การแคสต์หรือคอมพิวเตอร์ต่อ HDMI
